# ds-analytics

**Figma Design System Auditor** — плагин Figma, который сам находит проблемы в файле и сам приводит дизайнера к месту проблемы.

Две оси ценности:

1. **Поиск проблем** — аудит слоёв, компонентов, переменных, структуры, контента и a11y.
2. **Решение проблем** — навигация к ноде в один клик, массовые автофиксы с превью, undo одной транзакцией, ignore-лист.

Дифференциация против насыщенного рынка линтеров хардкода (Design Lint и аналоги):

- **Impact analysis** — что сломается, если удалить токен / переименовать компонент / схлопнуть варианты.
- **Adoption-тренд** — снапшоты состояния файла во времени. Разовый скан — инструмент, тренд — продукт.
- **Layer-aware правила токенов** — проверка соблюдения слоёв ДС, а не факта наличия переменной.

## Статус

**Pre-alpha. Правил ещё нет.** Собран каркас: сборка, границы `main`/`ui`, тестовая инфраструктура, CI. Плагин импортируется в Figma и показывает UI, но ничего не проверяет.

Ближайший гейт — не написание кода, а **валидация сигнала правил на боевом файле** (см. аудит, блок A). При сигнале < 70% продукт не запускается. Четыре механизма из паспорта (undo массового фикса, хэш ноды, dynamic-page обход, библиотечные переменные) пока не имеют опоры в API — блоки B1–B4 аудита; код в `scanner/` и `fixes/` не пишется до решений по ним.

## Разработка

```
npm ci
npm run verify     # typecheck + lint + test + build + бюджет размера
npm run build      # затем Plugins -> Development -> Import plugin from manifest
```

Границы из паспорта держат не договорённости, а раздельные `tsconfig` и ESLint: React в `src/main` не компилируется, `figma.*` в `src/ui` не линтуется, синхронные Figma-API запрещены правилом. Подробнее — [CONTRIBUTING.md](CONTRIBUTING.md).

## Tech stack

TypeScript (strict) · Figma Plugin API · React 18 + Vite · Tailwind v3 · Shadcn UI · Vitest

Целевой размер UI-бандла — до 500 KB.

## Лицензия

**Не определена.** Репозиторий публичный, но без файла лицензии — по умолчанию это «все права защищены»: смотреть можно, использовать и форкать юридически нельзя. Выбор зависит от модели монетизации (см. блок D аудита) и является блокером публикации в Community.
